# Reproducibility and privacy boundary

## Public release checks (no participant data needed)

From the release root, run `python analysis_code/verify_public_release.py` to verify SHA-256 manifest entries. Inspect the aggregate CSVs and tables directly; the 40 HIGH-DOWN rows in the supplementary table match the selected WP-06 HIGH rows. To rebuild the supplied supplementary document locally, install an appropriately licensed TeX distribution and run `latexmk -pdf supplementary_material.tex` from `supplementary/`. The source reads the included `supplementary/tables/` files. These checks do not rerun statistical analysis.

## Full analysis reproduction requires separately controlled inputs

The public release does **not** include the 521 source CSVs, original RAR, original participant-level model inputs/predictions/outcomes, private key maps, segment inventories, original manifests that expose paths/identifiers, or the private exclusion list. The authors’ repository and Zenodo dataset are linked in `DATA_PROVENANCE.md`; obtain source data directly and use it only under applicable terms and approvals. Reconstructing the exact original eligible cohort also requires authorized access to the private project eligibility/metadata records. The included aggregate files alone cannot reproduce individual-level analyses or regenerate the original sealed hashes. Do not attempt to infer or guess private exclusions.

`analysis_code/` mirrors the historical project script layout under that directory, but is a privacy-adapted source snapshot, not a self-contained executable original repository. The WP-02 input preparation now reads `analysis_code/private_inputs/primary_a_exclusions.json` with an `excluded_identifiers` array supplied locally by an authorized holder. The WP-06 prep uses the environment variable `FATIGUE_WP06_PRIVATE_HANDOFF`; do not distribute that archive or its paths. WP-05 report text has its workstation output path removed. No such private files are included here. These adaptations change script hashes: historical write-once manifests and clean-rerun checks cannot be asserted byte-identical using this snapshot without the separately controlled original code and authority files.

A qualified authorized reproducer must work in an isolated private workspace, supply the original required contracts, manifests, prediction/cohort evidence and private inputs, review frozen method specifications in `aggregate_results/`, and use the existing stage scripts in their documented WP-02 → WP-04 → WP-05 → WP-06 order. The archived scripts may write person-level intermediate data; do not place generated intermediates in a public directory. Compare aggregate outputs against the included tables only after applying the original eligibility and analysis contracts. The original clean-run environment included Python 3.13.15, NumPy 2.2.6 and Matplotlib 3.11.1; availability and dependency licenses must be assessed independently. The exact historical run remains conditional on private inputs and original hashes; this package does not claim independent end-to-end reproducibility from public files alone.

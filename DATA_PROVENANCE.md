# Data provenance

Mohapatra et al. (2024), “Wearable network for multilevel physical fatigue prediction in manufacturing workers,” *PNAS Nexus* 3(10), pgae421. DOI: https://doi.org/10.1093/pnasnexus/pgae421.

The direct processed input was the authors’ WorkerFatigue repository, https://github.com/payalmohapatra/WorkerFatigue, pinned commit `63bc71950a323b3fabe4eb73881d041c72faf091`, archive `Predictive_Models/MxD_Data_User_Study.rar`, SHA-256 `5e542bae625f8e5d0a7d47f072c94059dc20d5ec9c177b8b13a773dd86590940`. All 521 local CSV files matched the corresponding archive members by size and SHA-256. The original data and RAR are not included.

The separate upstream dataset is https://doi.org/10.5281/zenodo.12788571. The exact byte-level relationship between that Zenodo ZIP and the GitHub RAR has not been independently verified; the Zenodo ZIP is not represented as the direct source of the 521 local CSVs.

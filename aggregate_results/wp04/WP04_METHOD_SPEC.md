## Outcome-blind construction

The Stage-1 process reads header names and uses NumPy `loadtxt(usecols=...)` to project only Time and 15 gyroscope columns; unselected fields are never converted, materialized in the returned data, evaluated, or used. It does not open downstream results, inventory outcome flags, prediction eligibility, or survey files. Hashing source bytes for provenance is not semantic access to their fields. This computational blindness does not mean the executor is unaware of the baseline scientific results.

## Paired analysis

Inner join frozen ACC_A and ACC_B authoritative transition rows on participant, task, from_segment, to_segment, retaining next-segment eligible features only. transition_index is the numeric index of segment_j (1–4). Do not expand primary eligibility. Primary delta = B agreement minus A agreement. Ordinary least squares includes intercept, Composite indicator (Harnessing reference), transition_index, and pooled z_arm_dominance. Standardize across all shared transitions once with population SD (ddof=0); hold this scale fixed in bootstrap and robustness checks. Equal transition weights define the regression estimand; uncertainty clusters by participant. This is an association, not a causal model.

Draw 10,000 samples of N participant IDs with replacement using NumPy default_rng(20260926). Each draw carries all that participant's transitions and both tasks together, using cluster multiplicities as weights. Percentile 2.5/97.5 intervals; exclude and count rank-deficient draws. Use the same draws for delta, A, B and M0/M1. Report model coefficients and descriptive R², without relying on Gaussian errors. Bootstrap sign-tail p = min(1, 2*min((1+#coef<=0)/(B+1),(1+#coef>=0)/(B+1))); this is a descriptive bootstrap tail summary, not an exact null-randomization p-value.

M0 delta ~ task + transition_index. M1 adds primary z score. Magnitude attenuation = 100*(abs(task_M0)-abs(task_M1))/abs(task_M0); also report signed change. Negative control: A agreement; descriptive B-only: B agreement. Repeat separately for each secondary predictor, each with its own pooled ddof=0 z score, using complete cases only for that feature and reporting counts. If both secondary predictors are testable, Holm adjustment across the two relative-delta tests is the secondary mechanism family; also report separate Holm families for the two A control tests and two descriptive B-only tests. Primary inference is unchanged.

Task characterization uses the next active segment on shared transitions; average within participant/task first, then task means. Also report the full eligible frozen active-segment cohort independently of agreement values. For each cohort bootstrap participant IDs jointly for task means, and separately bootstrap matched participant differences for Composite-minus-Harnessing. This comparison uses only frozen predictor values, with analytic membership determined by the specified shared cohort.

Required robustness: matched-task participants; omit transition index; preserve pooled primary scale. Exact outcome/prediction ties and agreement=0 counts by family/task are reported. Participant clusters are never redefined as transitions. Compatibility requires Harnessing higher than Composite, negative directionally informative primary interval, and no comparable general FAM-A degradation. No causal mediation, localized-fatigue measurement, force/physiology measurement, scheduling experiment, or publication verdict.
